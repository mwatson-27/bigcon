# THE BIG CON

Online multiplayer evidence-board game (2–8). Open `bigcon.html` in a browser.

Looks like [jtportal](https://github.com/mwatson-27/jtportal) and [econbymistake](https://github.com/waxmotson/econbymistake): charcoal, teal `#168388`, aqua titles, Times New Roman, news ticker.

- One player hosts and shares the 5-letter room code
- Everyone else joins with **this same file**
- Needs internet the first time (PeerJS)

## This build

- 82 exhibits; cards are pushed apart so they do not overlap
- Quikstop opens in a different neighbourhood each game
- Player seating / first-to-move is shuffled at start
- 3 movement steps
- Wins: 8 connected (BANK + COMMODITY + MEDIA + 2 CHARTS), school trophy, or Bank Run (5 banks)
